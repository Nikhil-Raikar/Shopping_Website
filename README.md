# Shopping Website

A shopping website built with HTML and CSS. This is the first part of a comprehensive e-commerce application.

## 📖 Description

A frontend-focused shopping website showcasing product listings, shopping interface, and e-commerce elements built with HTML and CSS.

## 🔗 Live Website

**[Visit the Shopping Website](https://nikhil-raikar.github.io/Shopping_Website/)**

## 🛠️ Technology Stack

- HTML5
- CSS3

## 🚀 Features

- Product catalog display
- Shopping interface
- Responsive design
- Modern and clean UI
- Product categories
- Easy navigation

## 📁 Project Structure

```
Shopping_Website/
├── index.html          # Main HTML file
├── style.css           # Styling
└── README.md           # This file
```

## 💡 How to Use

1. Visit the live website link above, or
2. Clone the repository and open `index.html` in your browser
3. Browse through products
4. Explore the shopping interface

## 📝 Installation (Local)

```bash
# Clone the repository
git clone https://github.com/Nikhil-Raikar/Shopping_Website.git

# Navigate to the project directory
cd Shopping_Website

# Open index.html in your browser
```
